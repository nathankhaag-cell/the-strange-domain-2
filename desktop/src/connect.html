The Strange Domain

Connect to a node

Enter the address of the Domain Node you use, for example 192.168.1.20:8743 or https://node.example.com.

Check the node's certificate

This node uses a certificate this computer does not trust, usually because the node made it itself. Make sure this fingerprint matches the one in the node's log before you continue.

You can change the node later from File, Change node.
